Voici quelques commandes qu'on a appris :

1. git add NomFichier ---> ajoute un fichier a la branche danns laquelle npous sommes

2. git branch NomBranche ---> liste les branches si utiliser sans nom sinon créer une branche avec le nom demander

3. git checkout -b NomBranche ---> cette commade sert à créer une nouvelle branche.

4. git clone Url ---> télécharge et copie un dépôt GitHub existant

5. git commit -m "msg" ---> fait une sauvegarde de l'instant 

6. git log ---> voir l'historique des commits effectués.

7. git pull origin main ---> récupérer tout le travail qui a été fait sur le main.

8. git status ---> voir si les fichiers qui ont été ajoutés à Git sont sauvegardés ou non.

9. git push ---> envoie les commits de la branche sur laquelle on est vers GitHub

10. git init ---> sert à initialiser github dans le dossier actuel (ou le recharger si il est déjà installé)
